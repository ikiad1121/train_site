# 鉄道用サイト
## 1. 目的
CSVで作った鉄道ダイヤグラムのデータ取得ならびに取得データの抽出・編集などを行うシステムの構築

## 2. ターゲット
日常的に鉄道を利用し、スムーズに移動情報を確認したい利用客

## 3. できること
- 駅案内(基本情報や構内案内など)<br>
- 時刻表の表示(駅情報とダイヤグラムを照合し、指定された駅からの出発時刻を提供)<br>
- 列車の乗換案内(入力した出発駅・到着駅・時刻のデータとダイヤグラムを照合し、スムーズな移動ルートを提供)

## 4. こだわり
デザインよりまず<strong>ユーザーから見た利便性</strong>を重点に置いており、無駄をなくし体感的にサイトを動かせるようにしている。

## 5. 得られた知見
元々が鉄道ファンということもあって鉄道をテーマとしたものを何か作りたいということとなったのだが、鉄道ダイヤのデータベースの構築や取り扱いは簡単ではなく、jsonだとデータの構築が難しそうだと考え、jsonにはこだわらずそもそもが表として管理できるCSVを選択した。<br>
<strong>「jsonとCSV、MySQLの使い分けをどうするか」</strong>といった課題、つまり<strong>「開発・保守のしやすさを踏まえた使用言語・技術の選定」</strong>が今回の鉄道公式サイトのキーだったのだろうと考えられる。
